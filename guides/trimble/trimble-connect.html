Overview

Use this guide when Trimble Connect will not show the project you were invited to, the SketchUp or Tekla integration cannot reach the project, or file uploads fail.

Overview

Trimble Connect is a cloud collaboration platform for sharing project models, drawings, and documents between office and field teams.

Most Connect tickets are missing project invitations, signing in with the wrong Trimble ID, or being on the wrong region's Connect URL.

Plain English

What this app is usually used for

A short, jargon-light description so users know they are on the right page.

What this app is usually used for

Cloud-based construction and AEC collaboration platform with web, desktop, and mobile clients for project folders, IFC model review, and field-to-office sharing.

It is part of the Trimble family covered in our app help.

Common problems

Common problems

These are the problems people run into most often with this app.

I was invited but the project is not in my list

You sign into Trimble Connect but the expected project is missing.

Likely fix

Confirm the email you sign in with exactly matches the email the project owner invited, and ask the support team to resend the invitation if needed.

What to collect

Send your Trimble ID email, the project name, and a screenshot of your Connect project list.

SketchUp or Tekla integration cannot see the project

The integration in SketchUp or Tekla will not sign in or the project does not appear there.

Likely fix

Confirm the extension is up to date, the Trimble ID in the extension is the same one that works in the browser, and you have permission on that project.

What to collect

Send the host app and version, the extension version, your Trimble ID, and the project name.

Uploads fail or stall

You try to upload a file or model but the upload does not finish.

Likely fix

Try a small test file first, confirm you have Edit or support team role on the destination folder, and try a different network if your office network is restrictive.

What to collect

Send the file size, the project, the folder, and a screenshot of the upload error.

First things to try

First things to try

Try these stable, low-risk steps before changing the app or computer.

Quick checks before you change anything

  • Which Trimble ID (email) are you signing in with at https://web.connect.trimble.com?
  • Which project name and which region (US, EU, APAC) was the invitation for?
  • Is the failure in the web app, the Windows desktop app, the SketchUp extension, or the Tekla integration?
  • Did the issue start after a Trimble ID email change, role change, or new computer?

Try these fixes first

  • Confirm what you can see at https://web.connect.trimble.com in the browser before troubleshooting any client.
  • Make sure your Trimble ID email exactly matches the email the project owner used in the invitation.
  • If you switched phones or laptops, you may need to re-approve sign-in or multi-factor sign-in on the new device.

Slow down

Do not do this yet / warnings

Skip these steps until you have collected the information below or until support asks you to. They can lose data or hide the real problem.

Avoid these until support says it is safe

  • Do not uninstall or reset Trimble Connect before you have tested a second file, project, or mailbox.
  • Do not delete local sync folders, profiles, or project saved local data until the browser or web version of the same content is known to be correct.
  • Do not change passwords, multi-factor sign-in settings, or default apps in the middle of troubleshooting unless support asks you to.
  • Do not run repair tools, clean-installs, or advanced system changes without confirming a backup or known-good copy of any work in progress.

What support needs

What details support needs

Collect these details before you contact support. The more you send up front, the less back-and-forth you will need.

Send these details

  • A screenshot of your Trimble Connect project list at https://web.connect.trimble.com.
  • Your Trimble ID email.
  • The project name and folder involved.
  • The host app and version if you are using a SketchUp or Tekla integration.

Licensing & access

Licensing / access notes

Use these checks when the app says Trial, Unlicensed, Subscription Required, or opens with the wrong account.

Licensing / access checks

  • Connect access is invitation-based — your Trimble ID email must match exactly the email the project owner invited.
  • If your project lives in a specific region (US, EU, APAC), you may need to use that region's Connect URL.
  • There is no separate paid seat for basic Connect access in most projects — the project owner controls who joins.

More checks

More setup checks

These are install, update, and follow-up checks that are usually safe after the first checks above.

Install / update basics

  • There is no required install — Connect runs in the browser at https://web.connect.trimble.com.
  • If you need a desktop folder of project files, install Trimble Connect Desktop (Sync) from the Trimble download page.
  • For SketchUp or Tekla, the integration extension is installed from inside the host app or the Extension Warehouse.

More things to check

  • Have the user verify at https://web.connect.trimble.com first before blaming the desktop app.
  • Confirm the project invite went to the same email the user is signing in with — Trimble IDs are email-exact.
  • Check which region the project lives in (some users sign into the wrong region's Connect URL).
