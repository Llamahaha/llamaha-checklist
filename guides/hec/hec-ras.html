Overview

Use this guide when HEC-RAS will not open the study data you expect, acts differently after a version change, or fails when you try to run or review a model.

Overview

HEC-RAS is used for hydraulic modeling, geometry review, terrain-backed workflows, and floodplain analysis.

Most HEC-RAS issues come from version differences, missing project data paths, or one study or data file behaving differently than the rest.

Common problems

Common problems

These are the problems people run into most often with this app.

One study or project opens incorrectly

The app launches, but one project or model file, study, or project will not open or does not behave the way you expect.

Likely fix

Test a second known-good file and compare the file path first so you can separate a data problem from an app problem.

What to collect

Send the exact study or data file name, where it is stored, and the message or screenshot you see.

The app feels wrong after a version or computer change

The same HEC-RAS workflow used to work, but now looks different or fails after a reinstall, update, or computer move.

Likely fix

Confirm the approved version and compare the same project on another working computer before changing project data.

What to collect

Send the current version, the previous version if you know it, and whether another approved computer still works.

First things to try

First things to try

Try these stable, low-risk steps before changing the app or computer.

Quick checks before you change anything

  • Did the problem start after moving to a new computer, changing versions, or opening a different HEC-RAS project?
  • Does the issue affect one project or model file or every HEC-RAS workflow on the computer?
  • Are the project files stored locally, on a network path, or in a shared engineering folder?
  • Can another approved computer open the same study or data set?

Try these fixes first

  • Compare the failing study or data file to a second known-good one before reinstalling the app.
  • Keep the exact version and one affected project name ready before contacting support.
  • If files are on a network path, confirm the path is still reachable from the computer first.

Slow down

Do not do this yet / warnings

Skip these steps until you have collected the information below or until support asks you to. They can lose data or hide the real problem.

Avoid these until support says it is safe

  • Preserve project folders, terrain references, RAS Mapper content, and exported results before uninstalling.

What support needs

What details support needs

Collect these details before you contact support. The more you send up front, the less back-and-forth you will need.

Send these details

  • A screenshot of the exact HEC-RAS message or screen where the problem happens.
  • The exact project, study, or data file name involved in the problem.
  • The HEC-RAS version shown in the app.
  • A note about whether another approved computer can open the same data.

Licensing & access

Licensing / access notes

Use these checks when the app says Trial, Unlicensed, Subscription Required, or opens with the wrong account.

Licensing / access checks

  • HEC-RAS is generally used without a separate paid end-user seat, so support usually depends on the approved version and the project data you are opening.
  • If the app opens but the study does not, note the exact project or data file name before changing the installation.
  • If your team standardizes on a specific version, include that version when you contact support.

More checks

More setup checks

These are install, update, and follow-up checks that are usually safe after the first checks above.

Install / update basics

  • Use the approved HEC-RAS version for your team and restart the computer after install or update if Windows asks you to.
  • Open HEC-RAS first, then test one smaller known-good study or data file before you open the project that is failing.
  • If the workflow depends on shared GIS, terrain, or DSS content, confirm those paths are still available after setup.

More things to check

  • Test a second known-good study or data set before rebuilding the app.
  • Capture the exact file path, version, and whether another approved computer opens the same data.
  • Preserve project folders and exported results before repair or uninstall work.
