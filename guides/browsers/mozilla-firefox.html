Application Guide

Overview

Overview

Firefox is a browser some teams use for work sites, downloads, and extension-based workflows.

Most Firefox problems come from saved site data, add-ons, sign-in sessions, downloads, or a site simply behaving differently in Firefox than it does in another browser.

Plain English

What this app is usually used for

What this app is usually used for

General browser support for Firefox when web apps, downloads, saved sign-ins, or extensions are behaving differently than expected.

It is part of the Browsers family covered in our app help.

Common problems

Common problems

A work site behaves differently only in Firefox

The same site works elsewhere, but Firefox shows sign-in loops, display problems, or missing actions.

Likely fix

Restart Firefox and compare the site with another browser before changing add-ons or browser settings.

What to collect

Send the site URL, the Firefox version, and whether another browser works.

Downloads do not start or finish normally

Firefox opens the site, but downloads fail or do not go to the expected location.

Likely fix

Check where Firefox is set to save downloads and retry one simple file.

What to collect

Send the file type, the download behavior, and the site URL.

An add-on workflow stopped working

A work site or process depends on an add-on, but it no longer behaves normally in Firefox.

Likely fix

Capture the add-on name and compare whether the site itself still works without assuming the entire browser is broken.

What to collect

Send the add-on name, the site URL, and when the issue began.

First things to try

First things to try

Quick checks before you change anything

  • Is the issue tied to one work site, downloads, sign-in, or an add-on you rely on?
  • Does the same site work in another browser on the same computer?
  • Did the issue begin after a Firefox update or an add-on change?

Try these fixes first

  • Compare the same site in another browser before you assume the site itself is down.
  • If downloads fail, test one simple file and note where Firefox is trying to save it.
  • If an add-on is part of the workflow, capture its name and whether the issue began right after it changed.
  • Keep the exact site URL before clearing settings or contacting support.

Do not do this yet / warnings

Avoid these until support says it is safe

  • Before removing Firefox, note any saved bookmarks, passwords, or work extensions you still need.

What support needs

What details support needs

Send these details

  • A screenshot of the exact Firefox message or failing page.
  • The site URL and the Firefox version.
  • The add-on name if one is involved.
  • A note about whether the same site works in another browser.

Licensing & access

Licensing / access notes

Licensing / access checks

  • Firefox itself does not normally use a paid product license for browsing.
  • Access still depends on the work accounts and websites you use in the browser.
  • If a site works in another browser but not Firefox, include that comparison when you contact support.

More checks

More setup checks

Install / update basics

  • Update Firefox to the latest supported version, then close and reopen the browser.
  • Retry the same site or download after the restart.
  • If an add-on is involved, note the add-on name before contacting support.
