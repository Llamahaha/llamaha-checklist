Application Guide

Overview

Chrome is a common browser for work websites, downloads, cloud apps, and single sign-on pages.

Most Chrome problems come from saved site data, blocked pop-ups, extensions, download settings, or the site behaving differently in one browser than another.

Plain English

What this app is usually used for

General browser support for work websites, downloads, passwords, extensions, and default-browser behavior in Chrome.

It is part of the Browsers family covered in our app help.

Common problems

Common problems

A work site will not sign in correctly

The site opens, but sign-in loops, closes, or never finishes loading your work session.

Likely fix

Try the same site in another browser and, if Chrome is the only one affected, close and reopen Chrome before retrying.

What to collect

Send the site URL, the exact sign-in behavior, and whether another browser works.

Downloads or file-opening actions fail

The site opens, but downloads do not start or files do not hand off to the expected desktop app.

Likely fix

Check Chrome's download prompt and save-location behavior, then test one simple file again.

What to collect

Send the file type, the site URL, and a screenshot of the browser message if one appears.

One site works in another browser but not Chrome

The same work site behaves normally in another browser, but not in Chrome.

Likely fix

Restart Chrome and note whether the problem is tied to one site only before changing extensions or browser settings.

What to collect

Send the site URL, the Chrome version, and the name of the other browser that works.

First things to try

First things to try

Quick checks before you change anything

  • Is the problem with one work website, all sites, downloads, sign-ins, or opening files from the browser?
  • Does the same site work in another browser on the same computer?
  • Did the issue begin after a Chrome update, a browser extension change, or a password or account change?

Try these fixes first

  • Check whether the same site works in another browser before clearing anything in Chrome.
  • If pop-ups or sign-in pages are blocked, look for blocked pop-up or site-permission notices near the address bar.
  • If downloads fail, check Chrome's download prompt and file location settings.
  • If only one site is failing, note the exact URL before removing extensions or clearing site data.

Do not do this yet / warnings

Avoid these until support says it is safe

  • If Chrome is your default browser, note any saved passwords, bookmarks, or work extensions you still need before removing it.

What support needs

What details support needs

Send these details

  • A screenshot of the browser message or the failing page.
  • The exact site URL involved.
  • The Chrome version from the browser settings.
  • A note about whether the same site works in another browser.

Licensing & access

Licensing / access notes

Licensing / access checks

  • Chrome itself does not normally use a paid product license for work browsing.
  • Access still depends on the work account you sign in with on the site and any company-required browser profile or sync settings.
  • If a website works in Edge or another browser but not Chrome, note that before contacting support.

More checks

More setup checks

Install / update basics

  • Update Chrome to the latest supported version, then close and reopen the browser.
  • Test the affected work site in a new tab after the restart.
  • If downloads or file opening are involved, test one simple file after confirming Chrome is updated.
