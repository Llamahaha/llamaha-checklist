Helpful starting points

Shared notes

  • Identify whether the client uses named-user, floating, or file-based licensing before you troubleshoot the app itself.
  • Note the license-server or config-file details your team uses. They are easy to lose and hard to rediscover.
  • Protect local worksheets, templates, and engineering content before cleanup or rebuild.

FAQ

  • Does PTC always use the same license model? - No. PTC products can use named-user access, floating licenses, or local file-based licensing, so the license path needs to be documented per client.
  • Where should we troubleshoot license server problems first? - Start with the PTC license server logs and LMTOOLS or equivalent status checks. PTC guidance points there first for daemon, host, and port issues.
  • Does uninstalling the app fully reclaim access? - Usually not. Reclaim the entitlement or license-server assignment and keep any environment or workspace settings documented.

Common problems

Recurring vendor-wide problems

Usage issues

  • User launches the app but it cannot find a license: Verify the computer points at the right license source, check environment variables or config files, and confirm the server port is fixed and reachable.
  • PLM or repository connection errors appear: Review DNS, hostname resolution, and service connectivity first. PTC troubleshooting frequently points to infrastructure and directory settings rather than the client install alone.
  • Workspaces or local engineering files do not match expectations: Confirm the user's local workspace, vault path, and check-in state before making changes, especially during offboarding or rebuilds.

Setup / update tips

  • Installer fails on prerequisites or the wrong runtime: Use the supported installer launcher, confirm the target platform is supported, and verify the required Java or bundled runtime path instead of launching inner installer files directly.
  • Application opens but reports an error while fetching the license: Check the PTC license server logs, validate host name, host ID, daemon path, and confirm the license server and vendor daemon both show as up in LMTOOLS.
  • Install from network media behaves unpredictably: PTC troubleshooting guidance points to rerunning from local media and reviewing installer log paths if the media set is incomplete or the network response is too slow.
